# Хвост

Telegram-бот для групп. Приветствует участников, показывает правила, принимает жалобы и ведёт игру с рейтингом хвостов.

## Запуск на VPS

Нужен Python 3.11+ с SQLite 3.35+ и системной базой часовых поясов. Устанавливать пакеты через pip не нужно.

Передай токен бота через переменную окружения `BOT_TOKEN`. Запусти `python3 tail_bot.py`. В личке с ботом выполни `/myid` и передай полученный ID через `OWNER_ID`. Затем перезапусти бота и открой `/menu`. Для первого чата можно также задать `BOT_CHAT` как @username или числовой ID.

Добавь бота в нужную группу. Нажми **Добавить чат** в личном меню, затем отправь её @username или ID из `/chatid`. Для надёжной проверки прав на изменение правил и просмотр жалоб назначь бота администратором группы.

Для постоянной работы запусти скрипт как отдельную службу на VPS. Храни параметры службы с токеном вне репозитория. В одном экземпляре бота может работать только один процесс опроса Telegram. Данные находятся в `tail-bot.sqlite` рядом со скриптом. При переносе останови старую копию бота и перенеси базу вместе со скриптом.

## Mini App на GitHub Pages

1. Положи `mini_app.py` рядом с `tail_bot.py` на VPS. В окружении службы задай `MINI_APP_PORT=8080` и перезапусти бота. API слушает только на `127.0.0.1:8080`.
2. Настрой HTTPS на VPS и проксируй `/tail-api` на тот порт. Например, в Caddyfile для домена, указывающего на VPS:

   ```caddy
   bot.example.com {
       reverse_proxy /tail-api 127.0.0.1:8080
   }
   ```

3. В корне сайта создай `.env.local` со строкой `VITE_TAIL_BOT_API_URL=https://bot.example.com/tail-api`, подставив свой домен. Выполни деплой сайта. Для сайта на другом домене укажи его origin в `MINI_APP_ORIGIN` на VPS. По умолчанию разрешён `https://wildsens.github.io`.
4. В BotFather оставь текущую ссылку на страницу Tail Bot. Mini App должна открываться от имени того же бота, токен которого используется на VPS.

Владелец из `OWNER_ID` видит список подключённых групп и может добавлять новые. Репорты видны только действующим администраторам соответствующих групп, даже для аккаунта владельца бота. Для проверки прав Telegram боту нужны права администратора группы.

## Команды

- `/start`, `/help` — подсказка.
- `/rules`, `/setrules текст` — посмотреть или обновить правила группы. Обновлять правила могут администраторы.
- `/grow`, `/tail`, `/top` — увеличить хвост раз в киевские сутки, посмотреть длину и рейтинг.
- `/report причина` — пожаловаться ответом на сообщение.
- `/reports` — последние жалобы для администратора в личке.
- `/myid`, `/chatid` — ID аккаунта в личке или ID группы.
- `/menu` — список и добавление групп, доступные владельцу в личке.
